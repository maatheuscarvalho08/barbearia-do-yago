# Barbearia do Yago

Landing page (protótipo) da Barbearia do Yago — sua barbearia por assinatura, com unidades em Alcântara (São Gonçalo) e Maricá, RJ.

Página única em HTML/CSS/JS, sem build. Abra `index.html` por um servidor local ou veja publicada no GitHub Pages.

## Rodar local

```bash
python -m http.server 4599
```

Depois acesse `http://localhost:4599`.
